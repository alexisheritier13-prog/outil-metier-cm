## Dev Notes

### Décisions

- **`can_see_scoped`** ajoutée (alias sémantique de `can_see_idea`) pour ne pas réutiliser
  un nom trompeur ; `can_see_idea` reste tel quel pour l'Epic 7.1.
- **`default_tags text[]`** plutôt qu'une table de liaison : les templates sont légers,
  l'application ne fait que remplir le champ tags libre de `PostForm` (créés à la volée).
- **`setValue` de react-hook-form** : `PostForm` reste non contrôlé, le template met à jour
  3 champs sans remonter le formulaire. Le `<select>` se réinitialise après application.
- **Templates proposés** : `PostForm` filtre côté client sur le `clientId` observé — pas de
  requête dépendante du client, on charge tout ce qui est visible.
