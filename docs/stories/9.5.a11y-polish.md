## Dev Notes

### Décisions

- **`channel: 'chrome'`** : l'environnement a Chrome installé mais pas les
  binaires Playwright ; ce mode évite le téléchargement (~150 Mo) et suffit
  pour un audit local. CI E2E = action utilisateur ultérieure (secrets +
  navigateur).
- **axe bloque `serious`/`critical` seulement** : `moderate` / `minor` sont
  journalisés sans casser le build (bruit de règles « best-practice »).
- **Superposition `<button>` plutôt que ligne `role=button`** : seule façon
  d'avoir une ligne cliquable au clavier SANS imbriquer la case et la corbeille
  (patron accessible standard pour cartes/lignes actionnables).
- **`Segmented` vs `Tabs`** : quand il n'y a pas de panneau distinct (juste un
  filtre d'état), `Tabs` Radix crée un `aria-controls` mort ; `Segmented` est le
  bon primitif.
