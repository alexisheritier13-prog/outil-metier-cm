## Dev Notes

### Décisions

- **Surimpression = événements FullCalendar all-day non éditables** plutôt que
  `display: 'background'` (qui masque le libellé). Style `.fc-keydate` : transparent,
  bordure gauche, opacité réduite. `handleClick` ignore les événements sans `post`.
- **Projection côté client** (`keyDateOccurrences`) : le calendrier n'affiche qu'un mois,
  on génère les occurrences pour l'année courante + la suivante (suffisant pour la
  navigation usuelle) plutôt que de brancher `datesSet`.
- **`key_dates_for_client`** en `security definer` : jointure sur `clients.sector`,
  `is not distinct from` pour gérer les secteurs nuls proprement.
- **Overlay = tous les marronniers visibles** (RLS), pas filtré au client sélectionné du
  calendrier — un CM voit global + secteur + ses clients, ce qui est le périmètre utile.
