## Story

As a CM,
I want exporter le calendrier filtré au format .ics,
so that je le consulte dans Google Calendar ou Outlook.

## Acceptance Criteria

1. Bouton « Exporter .ics » sur les vues calendrier/liste ; exporte les posts du
   résultat filtré. ✅ (bouton dans l'en-tête de `PlanningPage`, toutes vues)

3. Le fichier est valide (RFC 5545) et s'importe sans erreur dans Google Calendar

   structure BEGIN/END vérifiée en test)
4. Tests unitaires sur la génération (échappement, fuseau, événements
   multiples). ✅

## Dev Notes

### Décisions

- **Générateur maison plutôt qu'un paquet npm.** Le besoin est étroit (un type
  d'événement, un seul fuseau) et le point délicat — un `VTIMEZONE` correct pour
  qu'Outlook respecte l'heure locale — se code en quelques lignes. Zéro dépendance
  ajoutée, comportement entièrement testé.
- **Heure locale + TZID, pas d'UTC.** `DTSTART;TZID=Europe/Paris:20260701T100000`
  plutôt qu'un `...Z` : le post est planardé sur une heure murale (saisie Paris),
  et l'export doit rester lisible même si le client relit dans un autre fuseau.
- **Durée fixe 30 min.** Le modèle n'a pas de durée de publication ; 30 min donne
  un bloc visible sans encombrer la journée.
- **Résultat filtré, pas toute la base.** Le bouton exporte exactement ce que
  `useFilters` a sélectionné (client, statut, réseau, période, recherche).
